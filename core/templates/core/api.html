CityLog API

Scopri come integrare gli endpoint di CityLog nei tuoi progetti.

Le API di CityLog consentono di accedere ai dati sulle segnalazioni pubbliche e integrarli in altre applicazioni, analisi o dashboard.

📌 Cos'è CityLog API?

CityLog offre un set di API REST per:

  • Ottenere l'elenco delle segnalazioni.
  • Inviare nuove segnalazioni.
  • Recuperare informazioni geolocalizzate.
  • Effettuare analisi sui dati raccolti.

🔗 Endpoint principali

Gli endpoint principali disponibili:

Metodo Endpoint Descrizione
GET /api/reports/ Restituisce l'elenco delle segnalazioni pubbliche.
POST /api/reports/ Permette di inviare una nuova segnalazione.
GET /api/reports/{id}/ Restituisce i dettagli di una specifica segnalazione.

📡 Esempi di utilizzo

1. Ottenere l'elenco delle segnalazioni con `curl`:

curl -X GET https://citylog.cloud/api/reports/

2. Inviare una nuova segnalazione con `curl`:


curl -X POST https://citylog.cloud/api/reports/ \
     -H "Content-Type: application/json" \
     -d '{"latitude": "45.4642", "longitude": "9.1900", "image_url": "https://example.com/image.jpg"}'

🔑 Autenticazione

Per alcune operazioni, è necessario autenticarsi tramite un API Key.

Esempio di richiesta autenticata:


curl -X GET https://citylog.cloud/api/reports/ \
     -H "Authorization: Token YOUR_API_KEY"

Puoi ottenere un'API Key registrandoti su CityLog.
