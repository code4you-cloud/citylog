Roadmap dello Sviluppo

Ecco come le donazioni aiuteranno il progetto a crescere.

  • ✔ Fase attuale — Beta Pubblica
    • Raccolta segnalazioni ambientali
    • Interfaccia minima funzionante
    • Dashboard interna moderatori
  • 🔧 Prossimo step — Sviluppo API Open
    • API per app mobile e applicazioni esterne
    • Documentazione tecnica pubblica
    • Accesso in lettura ai dataset ambientali
  • 🧠 Step futuro — Machine Learning
    • Riconoscimento automatico dei rifiuti
    • Classificazione stato dei tronchi e alberature
    • Stima volume ingombro e pericolosità
  • 🌍 Step avanzato — Mappa interattiva OSM
    • Layer tematici su OpenStreetMap
    • Statistiche ambientali per quartiere
    • Integrazione con enti locali
  • ⚖ Eventuale — Azioni di tutela ambientale

    Possibili solo se supportate dai cittadini e nel pieno rispetto delle leggi.
